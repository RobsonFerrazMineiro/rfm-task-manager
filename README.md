Bem-vindo ao RFM Task Manager! Este projeto foi desenvolvido para gerenciar tarefas de forma eficiente e intuitiva. ## 🔍 Sobre o Projeto

O RFM Task Manager é um projeto de código aberto criado para gerenciar tarefas de forma eficiente e intuitiva. Ele foi desenvolvido com foco em uma experiência de usuário agradável e design responsivo. **Este projeto ainda está em desenvolvimento.**

## ⚙️ Instalação

Siga os passos abaixo para instalar o projeto localmente:

```bash
# Clone o repositório
git clone https://github.com/RobsonFerrazMineiro/rfm-task-manager.git

# Entre no diretório do projeto
cd rfm-task-manager

# Instale as dependências
npm install
```
